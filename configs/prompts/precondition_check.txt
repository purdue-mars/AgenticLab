## Understanding PDDL Predicates:
- `(hand-empty)`: The robot gripper is not holding any object
- `(holding ?obj)`: The robot gripper is currently holding the specified object
- `(clear ?obj)`: There is NO object on top of the specified object (the object's top surface is free/clear)
- `(on-table ?obj)`: The object is placed directly on the table surface
- `(on-top-of ?obj1 ?obj2)`: Object1 is placed on top of Object2
- `(not (predicate))`: The negation of the predicate (the condition is NOT true)
- `(and ...)`: ALL conditions inside must be satisfied
- `(or ...)`: AT LEAST ONE condition inside must be satisfied
